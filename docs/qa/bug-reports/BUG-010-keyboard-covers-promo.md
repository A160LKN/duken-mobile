# BUG-010. Клавиатура закрывает поле промокода и кнопку «Оформить заказ»

| | |
| --- | --- |
| Серьёзность | Major — пользователь не видит, что вводит |
| Приоритет | P2 |
| Происхождение | Найден при доработке автотестов после первого прогона CI |
| Окружение | Pixel 6 (эмулятор), Android 15 / API 35, arm64; debug 1.0.0 |
| Статус | Исправлен, закрыт регрессионным тестом |

**Шаги:** корзина с товаром → нажать на поле «Промокод».

**Ожидание:** поле, «Применить», итог и «Оформить заказ» поднимаются над клавиатурой.
**Факт:** клавиатура перекрывает всю нижнюю панель; поле ввода, итог и кнопку не видно —
[скриншот](img/BUG-010-keyboard-covers-promo.png).

**Как нашли:** тест вводил текст в элемент, найденный до открытия клавиатуры, и дефекта не видел. Когда ввод переписали
так, чтобы элемент искался заново после нажатия (это понадобилось для медленного эмулятора в CI), UiAutomator перестал
находить поле — оно было под клавиатурой.

**Причина:** приложение рисуется от края до края (`enableEdgeToEdge`), и в этом режиме `adjustResize` содержимое не
сдвигает — отступ под клавиатуру нужно задавать самому. Он был только на экране входа.

**Исправление:** `Modifier.padding(padding).consumeWindowInsets(padding).imePadding()` у `NavHost` — для всех экранов
сразу; `consumeWindowInsets` не даёт учесть высоту нижней панели дважды —
[DukenApp.kt](../../../app/src/main/java/kz/duken/mobile/ui/DukenApp.kt).

**Регрессия:** `test_checkout.py::test_keyboard_does_not_cover_promo_field` — низ поля и кнопки выше верхней границы
клавиатуры (берётся из `dumpsys window`, источник вставок `ime`). Проверено, что без исправления тест падает.
