# BUG-004. Каждая ссылка duken:// открывает новую копию приложения

| | |
| --- | --- |
| Серьёзность | Major — «Назад» ведёт себя непредсказуемо, растёт расход памяти |
| Приоритет | P2 |
| Происхождение | Найден автотестом при первом прогоне |
| Окружение | Pixel 6 (эмулятор), Android 15 / API 35, arm64; debug-сборка 1.0.0; сервер — stub-server |
| Статус | Исправлен, закрыт регрессионным тестом |

**Шаги**
1. Открыть приложение, перейти на «Заказы».
2. Открыть ссылку `duken://product/3` (из мессенджера; в тесте — `adb shell am start -a VIEW -d …`).
3. Нажать системную «Назад».

**Ожидание:** вернуться на «Заказы».
**Факт:** открывается другая копия приложения со своим экраном. После двух ссылок в задаче три `MainActivity`:
[выгрузка dumpsys](img/BUG-004-activity-stack.txt).

**Причина:** у Activity `launchMode` по умолчанию (`standard`): каждый интент VIEW создаёт новый экземпляр.

**Исправление:** `android:launchMode="singleTop"` — ссылка приходит в открытое приложение через `onNewIntent`,
где уже обрабатывалась — [AndroidManifest.xml](../../../app/src/main/AndroidManifest.xml).

**Регрессия:** `test_deeplinks.py::test_link_does_not_duplicate_app` (число Activity в задаче — 1),
`test_back_from_link_returns_to_previous_screen`.
