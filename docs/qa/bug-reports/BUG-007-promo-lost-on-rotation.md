# BUG-007. Применённый промокод пропадает после поворота экрана

| | |
| --- | --- |
| Серьёзность | Major — заказ оформляется без скидки, которую пользователь видел |
| Приоритет | P2 |
| Происхождение | Заложен в версию 1.0 намеренно (типичная ошибка), пойман автотестом |
| Окружение | Pixel 6 (эмулятор), Android 15 / API 35, arm64; debug-сборка 1.0.0; сервер — stub-server |
| Статус | Исправлен, закрыт регрессионным тестом |

**Шаги:** корзина → `WELCOME10` → «Применить» (скидка −18 999 ₸) → повернуть телефон.

**Ожидание:** скидка на месте. **Факт:** скидки нет, итог без неё; «Оформить заказ» создаёт заказ без промокода.

**Причина:** применённый код хранился в `remember { mutableStateOf() }` внутри экрана. Поворот пересоздаёт Activity,
`remember` очищается. Поле ввода было на `rememberSaveable`, поэтому текст в поле оставался — и это сбивало с толку.

**Исправление:** промокод — в `SavedStateHandle` ViewModel: переживает и поворот, и гибель процесса —
[CartViewModel.kt](../../../app/src/main/java/kz/duken/mobile/ui/cart/CartViewModel.kt).

**Регрессия:** `test_lifecycle.py::test_applied_promo_survives_rotation`.
