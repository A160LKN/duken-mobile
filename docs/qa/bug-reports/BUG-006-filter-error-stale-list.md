# BUG-006. Ошибка при смене категории показывает старый список под новым фильтром

| | |
| --- | --- |
| Серьёзность | Major — пользователь видит не те товары и не знает об ошибке |
| Приоритет | P2 |
| Происхождение | Найден автотестом с имитацией ответа 503 |
| Окружение | Pixel 6 (эмулятор), Android 15 / API 35, arm64; debug-сборка 1.0.0; сервер — stub-server |
| Статус | Исправлен, закрыт регрессионным тестом |

**Шаги:** каталог открыт → заглушка отвечает 503 на `GET /products` → выбрать категорию «Продукты».

**Ожидание:** экран ошибки с текстом сервера и кнопкой «Повторить».
**Факт:** чип «Продукты» выбран, а в списке все 18 товаров, включая смартфоны. Ошибки нет.

**Причина:** экран ошибки показывался, только когда список пуст; при смене фильтра старый список не очищался.

**Исправление:** ошибка после смены фильтра очищает список и показывает экран ошибки;
ошибка обновления свайпом оставляет список (он всё ещё верный) и показывает сообщение внизу экрана —
[CatalogViewModel.kt](../../../app/src/main/java/kz/duken/mobile/ui/catalog/CatalogViewModel.kt).

**Регрессия:** `test_network.py::test_filter_error_then_retry`.
