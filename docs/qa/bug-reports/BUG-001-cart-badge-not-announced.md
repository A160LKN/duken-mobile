# BUG-001. TalkBack не сообщает число товаров в корзине

| | |
| --- | --- |
| Серьёзность | Major — доступность (WCAG 2.1, 1.1.1 и 4.1.2) |
| Приоритет | P2 |
| Происхождение | Найден автотестом при первом прогоне |
| Окружение | Pixel 6 (эмулятор), Android 15 / API 35, arm64; debug-сборка 1.0.0; сервер — stub-server |
| Статус | Исправлен, закрыт регрессионным тестом |

**Шаги**
1. Войти, в каталоге нажать «В корзину» у любого товара.
2. Включить TalkBack, перевести фокус на вкладку «Корзина» внизу.

**Ожидание:** TalkBack читает «Корзина, товаров: 1».
**Факт:** читает только «Корзина». Значок с цифрой виден на экране, но в дереве доступности его нет.

**Доказательство:** [скриншот](img/BUG-001-badge-not-in-a11y-tree.png): значок «1» на экране есть, а в выгрузке `uiautomator dump`
у узла `nav_cart` нет ни текста «1», ни описания.

**Причина:** `NavigationBarItem` из Material 3 при показанной подписи вызывает `clearAndSetSemantics {}` для иконки,
а вместе с иконкой из дерева уходит и `BadgedBox` со значком.

**Исправление:** число товаров продублировано в `contentDescription` пункта навигации
(строка `cart_with_items` на русском и казахском) — [DukenApp.kt](../../../app/src/main/java/kz/duken/mobile/ui/DukenApp.kt).

**Регрессия:** `test_catalog.py::test_add_to_cart_updates_badge`, `test_cannot_add_more_than_stock` — число на значке
читается из описания для TalkBack, а не с картинки.
