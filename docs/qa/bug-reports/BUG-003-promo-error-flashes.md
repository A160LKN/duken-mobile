# BUG-003. Ошибка «Промокод не найден» мелькает и исчезает

| | |
| --- | --- |
| Серьёзность | Minor — скидки нет, а объяснения не видно |
| Приоритет | P3 |
| Происхождение | Найден автотестом при первом прогоне |
| Окружение | Pixel 6 (эмулятор), Android 15 / API 35, arm64; debug-сборка 1.0.0; сервер — stub-server |
| Статус | Исправлен, закрыт регрессионным тестом |

**Шаги:** корзина с товаром → промокод `NOPE` → «Применить».

**Ожидание:** под полем «Промокод не найден», пока пользователь не изменит код.
**Факт:** текст появляется на доли секунды и пропадает; автотест ни разу не успел его найти за 10 секунд.

**Причина:** после отказа сервера код сбрасывал применённый промокод, это запускало пересчёт корзины без него,
а пересчёт очищал `promoError` вместе с остальным состоянием.

**Исправление:** пересчёт не трогает ошибку промокода; она сбрасывается, только когда пользователь меняет поле
или снова нажимает «Применить» — [CartViewModel.kt](../../../app/src/main/java/kz/duken/mobile/ui/cart/CartViewModel.kt).

**Регрессия:** `test_checkout.py::test_unknown_promo_code`, `test_promo_with_minimum_total`.
