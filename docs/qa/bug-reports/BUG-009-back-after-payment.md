# BUG-009. После оплаты «Назад» и вкладка «Корзина» возвращают на экран успеха

| | |
| --- | --- |
| Серьёзность | Major — пользователь «заперт» в оформлении |
| Приоритет | P2 |
| Происхождение | Заложен в версию 1.0 намеренно (типичная ошибка), пойман автотестами |
| Окружение | Pixel 6 (эмулятор), Android 15 / API 35, arm64; debug-сборка 1.0.0; сервер — stub-server |
| Статус | Исправлен, закрыт регрессионными тестами |

**Шаги (два проявления)**
1. Оплатить заказ → на экране «Заказ оплачен» нажать системную «Назад».
2. Оплатить заказ → «Продолжить покупки» → добавить товар → вкладка «Корзина».

**Ожидание:** 1 — вкладка приложения; 2 — корзина с новым товаром.
**Факт:** 1 — на миг появляется форма оплаты оплаченного заказа и снова открывается «Заказ оплачен»: «Назад» не выводит
из оформления. 2 — вкладка «Корзина» открывает старый «Заказ №1 оплачен».

**Причина:** экраны оплаты и успеха добавлялись в стек вкладки «Корзина» без удаления; переход на вкладку сохранял
этот стек и восстанавливал при возврате.

**Исправление** — [DukenApp.kt](../../../app/src/main/java/kz/duken/mobile/ui/DukenApp.kt): после оплаты экран оплаты
удаляется из стека (`popUpTo(…) { inclusive = true }`); кнопки экрана успеха уходят на вкладку без сохранения
состояния оформления. Страница заказа перечитывает статус при каждом возвращении.

**Регрессия:** `test_checkout.py::test_back_after_payment_does_not_return_to_payment` (первая версия теста проверяла
только «не видна кнопка Оплатить» и пропускала дефект — усилена),
`test_permissions.py::test_allow_then_notification_on_next_payment` (вторая покупка подряд).
