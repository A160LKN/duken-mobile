# BUG-012. После 5 секунд бездействия корзина показывает «Нет подключения к интернету»

| | |
| --- | --- |
| Серьёзность | Major — ложная ошибка сети на основном пути покупки |
| Приоритет | P1 |
| Происхождение | Внесён исправлением BUG-005, найден смоуком против настоящего shop-api в CI |
| Окружение | GitHub Actions, эмулятор Android 15 x86_64, shop-api в Docker (uvicorn); локально — заглушка с keep-alive 5 с |
| Статус | Исправлен, закрыт регрессионными тестами |

**Шаги:** войти, положить товар в корзину, подождать больше 5 секунд, открыть корзину.

**Ожидание:** итог заказа.
**Факт:** под промокодом «Нет подключения к интернету», «Оформить заказ» недоступна —
[скриншот из CI](img/BUG-012-cart-offline-after-idle.png). Каталог при этом загружен: сеть есть.

**Причина:** uvicorn закрывает простаивающее keep-alive соединение через 5 секунд. OkHttp берёт его из пула, получает
обрыв и обычно сам повторяет запрос по новому соединению. Исправляя BUG-005 (тихий повтор оплаты), я отключил
автоповтор во всём клиенте — и вместе с повтором оплаты пропал этот безопасный повтор чтения.

**Почему не видели раньше:** локальная заглушка держала соединения бесконечно — устаревших соединений в пуле не
было. Во втором прогоне CI смоук прошёл: между запросами не было паузы дольше 5 секунд.

**Исправление** — [ApiClient.kt](../../../app/src/main/java/kz/duken/mobile/data/api/ApiClient.kt),
[Repositories.kt](../../../app/src/main/java/kz/duken/mobile/data/repo/Repositories.kt):
два клиента. Чтение и безопасные запросы — с автоповтором OkHttp. Оплата, создание и отмена заказа, регистрация —
без автоповтора и без пула соединений: устаревшего соединения у них не бывает, а повтор после обрыва решает пользователь.
Заглушка теперь закрывает простаивающие соединения через 5 секунд, как uvicorn.

**Регрессия:**
- `test_network.py::test_request_after_idle_keepalive_closed` — пауза 7 с, корзина считается; до исправления падал;
- `ApiErrorTest.readClientSurvivesConnectionClosedByServer` — сервер рвёт соединение после ответа, второй запрос проходит;
- `ApiErrorTest.writeClientDoesNotRetryPaymentAfterDrop` и тесты BUG-005 — оплата по-прежнему не повторяется сама.
